@AGENTS.md

A change to this repo starts with the `story` skill, `.claude/skills/story/`. It files the change as a story issue on GitHub, builds it on a branch once the owner labels it `ready`, and opens the pull request. The owner merges.

## Agent skills

### Issue tracker

Issues are GitHub issues on this repo, read and written with `gh`. See `docs/agents/issue-tracker.md`. The wayfinder map and its tickets are issues labelled `wayfinder:*`, and that file's "Wayfinding operations" section says how sub-issues, blocking and the frontier work here.
