Reframe. Add the analyzer rule IDE0073 and the `file_header_template` `SPDX-License-Identifier: MIT` to `.editorconfig`. Give each C# file under `src/` and `tests/` the header.

`Directory.Build.props` sets `EnforceCodeStyleInBuild` and `TreatWarningsAsErrors`. Each finding of a rule at `warning` therefore fails the build. IDE0073 flags each C# file whose header differs from `file_header_template`.

`.editorconfig`, in `[tests/**.cs]`, holds this paragraph in place of the paragraph that starts '[tests/**.cs]':

```ini
[tests/**.cs]
dotnet_diagnostic.CA2000.severity = none
dotnet_diagnostic.CA2213.severity = none
dotnet_diagnostic.CA1849.severity = none
dotnet_diagnostic.CA1031.severity = none
dotnet_diagnostic.CA2007.severity = none

[*.cs]
# A license header on every C# file.
file_header_template = SPDX-License-Identifier: MIT
dotnet_diagnostic.IDE0073.severity = warning
```

After the change, the first line of each `*.cs` file under `src/` and `tests/` is `// SPDX-License-Identifier: MIT`. `dotnet build` exits 0.

The program keeps its behaviour. Each public type and each public or protected member under `src/` stays as it is. Each test keeps passing. Every other line of `.editorconfig` stays as it is on `main`. Each project file, `Solution.slnx`, `Directory.Build.props` and `Directory.Packages.props` stay as they are on `main`. Each feature file under `specs/features/` stays as it is.
